# Kazi Mustafijur Rahaman — Portfolio

Static portfolio site. `index.html`, `kazi-rahaman.jpg`, and `.nojekyll` are the website files; `.nojekyll` tells GitHub Pages to serve them as-is.

## GitHub Pages deployment

Create a public repository named `k-m-rahaman.github.io`, upload the website files to the repository root, then enable Pages from **Settings → Pages → Deploy from a branch → `main` → `/ (root)`**.

The expected site address is `https://k-m-rahaman.github.io/`.
