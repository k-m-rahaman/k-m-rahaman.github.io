01 / COMPUTER VISIONFeatured · Prototype

EcoLens Pro

Recycling guidance, processed locally.

A smart-campus recycling concept that recognizes waste categories and turns sorting into a guided, multilingual experience. The model runs in the browser, keeping image inference on the device.

View project on GitHub ↗

Concept prototype; no measured accuracy or deployment impact claimed.

Problem
Make waste sorting more approachable while avoiding the need to send camera frames to a cloud service.
My contribution
Project lead; built the browser inference path, AI pipeline automation, persistent user state, multilingual interface, and dashboard.
Approach
Fine-tuned a YOLOv8-Nano model, exported a 5.9 MB FP16 ONNX model, and connected camera frames to local inference with ONNX Runtime Web.
Tools
YOLOv8ONNX RuntimeWebAssemblyJavaScriptHTML / CSSGoogle Colab
02 / GEO AIPrototype

DroneMap AI

From aerial imagery to mapped parcels.

An end-to-end cadastral mapping prototype exploring how computer vision and GIS can help identify parcel boundaries and prepare provisional property records.

View project on GitHub ↗

Provisional demo; not an official land record or survey service.

Problem
Explore a digital workflow for detecting parcel footprints and translating image coordinates into map boundaries.
My contribution
Built the application across its computer-vision service, mapping interface, spatial calculations, and certificate-generation flow.
Approach
Used instance segmentation for footprint detection, geospatial calculations for area estimates, and a manual review path for boundary edits.
Tools
PythonFastAPIYOLOv8LeafletTurf.jsFPDF
03 / GENERATIVE AIChallenge project

Student Performance Predictor

A study companion built for PromptWars 2026.

A small Streamlit app that takes study hours and attendance as inputs, estimates semester outcomes, and offers three AI-generated study tips.

View project on GitHub ↗

Challenge build; predictive performance has not been independently validated.

Problem
Give students a lightweight way to reflect on study habits and find practical next steps.
My contribution
Created the app experience and connected student inputs to a generated study-advice flow.
Approach
Combined a simple input-driven outcome estimate with Gemini-generated recommendations in a compact dark interface.

PythonStreamlitGoogle Gemini API
